# Nogma Site — UI Kit

Recreation of the **Nogma marketing site** — the public-facing landing page for the consultancy. Premium, direct, confident (Apple / Stripe / Uber references). Single scrolling page in `index.html`.

## Sections
1. **Nav** — sticky, dark blurred bar, lime wordmark + lime "Falar com a gente" CTA.
2. **Hero** — **black band** (primary): lime eyebrow, white headline with a lime accent phrase, dual CTA, trust line, and a petroleum "product peek" card showing live automations.
3. **Proof strip** — client wordmarks (placeholder names) in Agency.
4. **Serviços** — three service cards (Automação, Agentes de IA, Consultoria).
5. **Como funciona** — 4 numbered steps (lime chips).
6. **Resultados** — petroleum panel (mid-page accent break) with big Agency stat numerals.
7. **Depoimento** — centered pull-quote.
8. **CTA band** — full lime, petroleum text, solid CTA.
9. **Footer** — black, lime wordmark + lime section headings, link columns.

## Composition
Uses `Button, Badge, Card, Stat` from `window.NogmaDesignSystem_54b71f`; icons from `assets/icons.jsx`. Everything else is section CSS driven by design tokens.

## Notes
Client names, testimonial, and metrics are illustrative placeholders — swap for real content. No source site was provided; layout follows the brand's stated aesthetic (whitespace, subtle corners, strong type hierarchy, zero AI clichés).
